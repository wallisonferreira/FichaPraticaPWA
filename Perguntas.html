Perguntas e Respostas sobre Git

  1. O que são operações de "Commit", "Push" e "Pop" efetuadas num repositório?

    • Commit: registra as alterações feitas na área de trabalho local.
    • Push: faz o envio das alterações locais para o repositório remoto.
    • Pop: faz a remoção de um commit da história do repositório local.

  2. Quais são as vantagens de usar Branchs num repositório git?

    • Permite que pessoas trabalhem em ramos distintos de desenvolvimento, facilitando a colaboração e organização do projeto.
    • Permite também a resolução de conflitos de forma mais eficiente quando há múltiplas pessoas trabalhando sobre o mesmo artefato de código.

  3. Nos Merges de conteúdos resultantes de um "Pop" podem resultar em conflitos. Em que consistem e como podem ser resolvidos esses conflitos?

    Conflitos de merge podem ocorrer quando uma alteração é sobreposta sobre outra alteração. Para o caso do Pop, onde a alteração é removida, o conflito precisa ser resolvido manualmente, onde o usuário escolhe o que deseja manter e o que deseja remover.

  4. "Clone" e "Fork" são formas diferentes de replicar um repositório Git. Quais as diferenças entre eles?

    Clone faz uma cópia completa do repositório remoto para o repositório local.

    Fork cria uma cópia do repositório remoto para o repositório remoto do usuário, de tal maneira que suas alterações não afetem o repositório original.
